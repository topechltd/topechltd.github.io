GXA5104 — 4‑Channel 24‑Bit 51.2 kHz Wireless DAQ Module

4‑Channel · 24‑Bit · 51.2 kHz Wireless DAQ Module

The GXA5104 is a high‑performance wireless data acquisition module designed for precision measurement of mechanical vibration and acoustic signals. Supporting both USB and UWB high‑speed transmission, it delivers 24‑bit resolution at sampling rates up to 51.2 kHz across four independent input channels. The module adopts IEPE sensor power‑supply mode and provides a complete SDK for secondary development, enabling seamless integration into custom test and monitoring systems.
