GXE0002 — WinUSB Base Board STM32F405

WinUSB Base Board · STM32F405 · USB HS

The GXE0002 is a WinUSB base board paired with an STM32F405RGT6 core board. It features an onboard USB3300 chip providing a GXE expansion module interface, capable of extending SPI, UART, I2C, CAN and other signals. All unused IO pins are brought out for flexible development. Onboard peripherals include an SD card interface, 2 LEDs, and 2 buttons.
