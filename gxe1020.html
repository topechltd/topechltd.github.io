GXE1020 — Electric Screwdriver Module with Digital Display

Electric Screwdriver Module · Digital Display

The GXE1020 is an expansion module designed specifically for electric screwdrivers, enabling simple upgrades to traditional tools. It counts the number of screws in each tightening cycle, effectively preventing missed or over-tightening. Features include digital tube display, button-based parameter configuration, power-off data retention, and wire detection functionality.
