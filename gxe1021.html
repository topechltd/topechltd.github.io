GXE1021 — Wireless Networked Electric Screwdriver Module

Electric Screwdriver Module · Wireless · Networked

The GXE1021 is the upgraded version of the GXE1020, adding wireless communication capabilities. It transmits bolt tightening status data in real-time to a host computer for display, while also storing data for post-event traceability. It retains all original features including digital tube counter display, button-based parameter configuration, power-off data retention, and wire detection.
